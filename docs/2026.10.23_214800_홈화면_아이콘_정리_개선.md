# 홈 화면 상단 아이콘 정리 및 전통 엠블럼 타이틀 개편 결과 보고서

> **실행 명령 프롬프트 원문:**  
> "방안 1 적용"

---

## 1. 개요 및 목적
- 안드로이드 최근 실행 앱(Recent Apps) 목록에서 시스템 런처 아이콘(`ic_launcher`)과 웹뷰 홈 화면 최상단 아이콘(`home-app-icon`)이 수직으로 맞닿아 겹쳐 보이는 현상을 근본적으로 해결했습니다.
- 홈 화면 내부의 중복된 `img.home-app-icon`을 제거하고, 한국 전통 장기의 멋을 살린 `[楚]`(청록) / `[漢]`(진홍) 미니 기물 엠블럼과 품격 있는 큰글씨 타이틀로 개편을 완료했습니다.

## 2. 세부 작업 내용

### 2.1 CSS 스타일 개편 ([`index.html`](file:///c:/Antigravity/Janggi%20for%20Seniors/index.html#L223-L270))
- 기존 `.home-app-icon` (90×90px) 스타일 제거
- 전통 기물 엠블럼 행(`.home-emblem-row`), 전통 기물 배지(`.emblem-piece.cho`, `.emblem-piece.han`), 중앙 그라데이션 디바이더(`.emblem-divider`) 스타일 신규 정의
- 타이틀 폰트 크기(`34px`) 및 자간(`letter-spacing: 2px`), 상하 여백 최적화

### 2.2 HTML 마크업 수정 ([`index.html`](file:///c:/Antigravity/Janggi%20for%20Seniors/index.html#L730-L745))
- 기존의 `<img src="icon.svg" ... class="home-app-icon">` 태그 완전 제거
- 품격 있는 `[楚] - [漢]` 엠블럼과 "청 춘 장 기" 큰글씨 헤더로 교체 적용:
  ```html
  <div class="home-brand-area">
    <div class="home-emblem-row">
      <div class="emblem-piece cho">楚</div>
      <div class="emblem-divider"></div>
      <div class="emblem-piece han">漢</div>
    </div>
    <h1 class="home-title">청 춘 장 기</h1>
    <div class="home-subtitle">어르신을 위한 큰글씨 효도 장기</div>
  </div>
  ```

## 3. 검증 결과

1. **브라우저 뷰포트 E2E 검증**:
   - 모바일 해상도(400 × 750)에서 렌더링 확인:
     - 상단에 중복되던 파란색 앱 런처 아이콘이 완전히 사라짐.
     - `[楚]`와 `[漢]` 전통 기물 미니 엠블럼과 굵은 고딕/명조 "청 춘 장 기" 타이틀이 단아하게 안착.
     - 상단 여백 확보로 [혼자서 장기두기], [둘이서 함께두기] 메뉴 버튼들이 시원하게 배치되어 시니어 터치 가독성 대폭 향상.
2. **최근 실행 앱(Recent Apps) 중복 제거 검증**:
   - 안드로이드 시스템이 카드 상단 헤더에 띄우는 런처 아이콘 1개만 단독으로 표시되어, 더 이상 위아래로 2개가 겹쳐 보이는 현상이 100% 원천 해결됨.
3. **안드로이드 네이티브 APK 재빌드**:
   - `android/app/src/main/assets/index.html` 최신 자산 동기화
   - `gradlew.bat assembleDebug` 빌드 성공 (`BUILD SUCCESSFUL in 13s`)
   - 최신 APK 산출: [`청춘장기_v1.0.0.apk`](file:///c:/Antigravity/Janggi%20for%20Seniors/청춘장기_v1.0.0.apk) (13.6MB)
