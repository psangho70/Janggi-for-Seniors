# 시스템 글자 크기 설정과 무관하게 앱 독립적 글자 크기 적용 원리 및 구현 방안

> **실행 명령 프롬프트 원문:**  
> "앱의 글자 크기를 시스템 설정을 따르지 않고 독립적 사용할 수 없을까?"

---

## 1. 결론: "네, 100% 완벽하게 독립적으로 분리할 수 있습니다!"

스마트폰의 [설정] > [디스플레이] > [글자 크기]가 **'최대'이든 '최소'이든 상관없이**, 안드로이드 운영체제의 시스템 글자 크기 간섭을 완전히 차단하고 **청춘장기 앱 자체만의 고유하고 안정적인 글자 크기로 독립 구동**하게 만들 수 있습니다.

---

## 2. 시스템 설정을 무시하고 독립적으로 동작하는 원리

### 2.1 안드로이드 WebView의 텍스트 줌 제어권 강제 (`textZoom = 100`)
- 안드로이드 WebView는 기본적으로 스마트폰 시스템의 글자 크기 비율을 자동으로 물려받도록 되어 있습니다.
- 하지만 앱의 소스코드([`MainActivity.kt`](file:///c:/Antigravity/Janggi%20for%20Seniors/android/app/src/main/java/com/ghailab/senior/janggi/MainActivity.kt#L79-L91))에서:
  ```kotlin
  webView.settings.textZoom = 100
  ```
  속성을 지정하면, 안드로이드 OS가 앱에게 주는 **"글자 크기를 150%, 200%로 키우라"는 시스템 명령을 앱이 강제로 차단/무시**합니다.
- 따라서 사용자가 폰 글자 크기를 아무리 크게 해놓아도, 청춘장기 앱 내부는 오직 **개발자가 정밀하게 설계한 100% 정규 비율**로만 고정됩니다.

### 2.2 웹 렌더러 폰트 자동 부스팅 차단 (`text-size-adjust: 100%`)
- CSS에 다음과 같이 선언합니다:
  ```css
  html, body {
    -webkit-text-size-adjust: 100%;
    text-size-adjust: 100%;
  }
  ```
- 모바일 브라우저 렌더링 엔진이 자체적으로 판단하여 글자를 키우는 현상을 원천 차단하여 완전한 독립성을 완성합니다.

## 3. 앱 독립 글자 크기 제어의 확장 가능성

단순히 시스템 설정을 무시하여 고정하는 것을 넘어서, 원하신다면 다음과 같은 형태도 자유롭게 구현할 수 있습니다:

1. **[독립 고정형 (가장 추천)]**:
   - 시스템 설정을 100% 무시하고, 이미 어르신을 위해 큼직하게 최적화된 청춘장기 고유 레이아웃(기물 140%, 타이틀 34px, 버튼 22px)을 어떤 폰에서든 흐트러짐 없이 유지.
2. **[앱 자체 조절형 (선택 옵션)]**:
   - 스마트폰 설정은 무시하되, 청춘장기 앱 내부의 **[환경 설정]** 모달에서 어르신이 직접 **`앱 글자 크기: 보통 / 더 크게`**를 선택할 수 있게 하여, 앱이 깨지지 않는 안전 범위(100% ~ 112%) 내에서만 앱 독립적으로 확대 가능하도록 제공.
