# 시스템 글자 크기 독립 제어(textZoom 100% 고정) 적용 완료 보고서

> **실행 명령 프롬프트 원문:**  
> "진행" (이전 요청: "앱의 글자 크기를 시스템 설정을 따르지 않고 독립적 사용할 수 없을까?")

---

## 1. 개요 및 목적
- 스마트폰 시스템 설정에서 글자 크기를 '최대'로 지정한 어르신의 기기에서도 청춘장기 앱의 화면 비율과 글자 배율이 깨지지 않도록 시스템 폰트 상속을 완전히 차단했습니다.
- 안드로이드 WebView의 `textZoom = 100` 및 CSS의 `text-size-adjust: 100%`를 적용하여, 외부 OS 설정과 무관하게 언제나 개발자가 의도한 최적의 시니어 큰글씨 황금 레이아웃으로 독립 구동되도록 개선을 완료했습니다.

---

## 2. 세부 작업 내용

### 2.1 안드로이드 네이티브 WebView 텍스트 줌 100% 고정
- **파일**: [`MainActivity.kt`](file:///c:/Antigravity/Janggi%20for%20Seniors/android/app/src/main/java/com/ghailab/senior/janggi/MainActivity.kt#L80-L95)
- **적용 내용**:
  ```kotlin
  settings.apply {
      javaScriptEnabled = true
      domStorageEnabled = true
      databaseEnabled = true
      useWideViewPort = true
      loadWithOverviewMode = true
      setSupportZoom(false)
      displayZoomControls = false
      mediaPlaybackRequiresUserGesture = false
      cacheMode = WebSettings.LOAD_DEFAULT
      allowFileAccess = true
      allowContentAccess = true

      // 스마트폰 시스템 글자 크기(150%~200%) 강제 확대를 100% 무시하고 앱 고유의 큰글씨 황금 레이아웃으로 독립 고정
      textZoom = 100
  }
  ```

### 2.2 웹 표준 폰트 부스팅(Font Boosting) 방지
- **파일**: [`index.html`](file:///c:/Antigravity/Janggi%20for%20Seniors/index.html#L70-L75)
- **적용 내용**:
  ```css
  html, body {
    -webkit-text-size-adjust: 100%;
    -moz-text-size-adjust: 100%;
    -ms-text-size-adjust: 100%;
    text-size-adjust: 100%;
  }
  ```
