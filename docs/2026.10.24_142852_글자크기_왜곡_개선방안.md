# 스마트폰 시스템 글자 크기(텍스트 배율) 확대 시 앱 레이아웃 붕괴 원인 및 최적 개선 방안 보고서

> **실행 명령 프롬프트 원문:**  
> "연세 많으신 어르신들의 경우, 스마트폰의 글자 크기를 최대로 카워놓고 사용하시는 경우가 많습니다.  
> 현재 청춘장기 앱은 스마트폰의 글자 크기 설정 통제를 받다보니 앱 화면의 글자가 커지면 사용이 거의 불가능한 형태로 앱 화면이 보여집니다. 이문제를 개선하기 위한 최적의 방안을 제안해 주세요."

---

## 1. 현상 및 핵심 원인 분석

### 1.1 현상
- 스마트폰의 [설정] > [디스플레이] > [글자 크기와 스타일]에서 글자 크기를 '최대' 또는 상위 단계로 설정한 기기에서 청춘장기 앱을 실행할 경우:
  - 버튼 텍스트가 버튼 박스 밖으로 튀어나가거나 줄바꿈이 심하게 깨짐.
  - 상단 대국 스코어보드(`info-cho-score`, `info-han-score`) 및 플레이어 이름이 겹쳐서 가려짐.
  - 환경설정 모달 및 안내 카드의 내용이 세로로 2배 이상 길어져 버튼이 화면 바깥으로 밀려남.
  - 장기판 크기 비율 및 터치 조작 영역이 틀어져 정상적인 대국 진행이 불가능해짐.

### 1.2 기술적 원인
1. **Android WebView의 시스템 텍스트 줌(Font Scale) 강제 상속**:
   - 안드로이드 WebView는 기본적으로 OS의 글자 크기 비율을 그대로 상속받습니다.
   - 어르신들이 OS 글자 크기를 최대로 설정하면 WebView의 `textZoom` 속성이 자동으로 **130% ~ 200%**로 강제 팽창합니다.
   - 청춘장기 앱은 이미 시니어 어르신을 위해 기본 폰트 크기(20px~34px)를 일반 앱 대비 1.4배 이상 크게 설계해 두었는데, 여기에 시스템 확대율(1.5~2배)이 **중복 곱셈**되면서 비정상적으로 글자가 거대해지는 것입니다.
2. **CSS `text-size-adjust` 미지정**:
   - 웹 CSS 레벨에서 모바일 브라우저의 폰트 부스팅(Font Boosting) 방지 속성이 지정되어 있지 않아 브라우저 렌더러가 임의로 글자 크기를 조작함.

## 2. 최적의 개선 방안 (3단계 종합 솔루션)

### [해결책 1: 핵심 근본 처방] 안드로이드 WebView의 `textZoom = 100` 고정
- **적용 위치**: `MainActivity.kt`
- **구현 내용**:
  ```kotlin
  webView.settings.apply {
      // 스마트폰 시스템 글자 크기 확대(150~200%)에 의한 UI 파괴를 원천 차단
      textZoom = 100
      ...
  }
  ```
- **효과**:
  - 스마트폰의 글자 크기를 '최대'로 설정하든 '최소'로 설정하든, 청춘장기 앱은 언제나 개발자가 정밀하게 설계한 **어르신 전용 최적의 큰글씨 황금 레이아웃(100% 정규 비율)**으로 완벽하게 유지됩니다.
  - 단 1줄의 설정으로 모든 레이아웃 깨짐 현상이 즉시 100% 해결됩니다.

---

### [해결책 2: 웹 표준 방어벽] CSS 폰트 부스팅(Font Boosting) 방지
- **적용 위치**: `index.html` CSS
- **구현 내용**:
  ```css
  html, body {
    -webkit-text-size-adjust: 100%;
    -moz-text-size-adjust: 100%;
    -ms-text-size-adjust: 100%;
    text-size-adjust: 100%;
  }
  ```
- **효과**:
  - 모바일 브라우저/웹뷰 엔진이 텍스트 블록을 임의로 확대 해석하여 레이아웃을 틀어지게 만드는 현상을 이중으로 방어합니다.

---

### [해결책 3: 시니어 특화 안전 글자 크기 조절 옵션 (선택적 고도화)]
- **배경**:
  - 시스템 글자 크기에 무방비하게 레이아웃이 깨지도록 방치하는 대신, **앱 내부 [환경 설정] 모달에서 안전한 범위 내의 글자 조절 옵션**을 제공할 수 있습니다.
- **구현 내용**:
  - 환경 설정 모달에 `글자 크기: 보통(기본 큰글씨) / 조금 더 크게(112%)` 옵션 추가.
  - 레이아웃이 절대 깨지지 않는 안전 마진(100% ~ 112%) 범위 내에서만 정밀 조절되도록 제어.

---

## 3. 권장 조치 계획
1. **1단계**: `MainActivity.kt`의 WebView 세팅에 `textZoom = 100` 추가
2. **2단계**: `index.html`에 `text-size-adjust: 100%` 추가 및 버튼/헤더 텍스트 안전 마진 점검
3. **3단계**: 최신 APK 재빌드 및 스마트폰 시스템 글자 크기 최대 상태에서의 가상 검증
