## 1. 개요 및 목적
본 작업은 『청춘 장기 (Janggi for Seniors)』를 전 세계 어르신과 사용자들이 인터넷 브라우저 및 아이폰/안드로이드 스마트폰에서 별도의 앱 설치 절차 없이 접속하여 즐길 수 있도록, **GitHub Pages 실시간 웹 서비스 환경(`https://psangho70.github.io/Janggi-for-Seniors/`)**을 완벽하게 구축하고 자동 배포(CI/CD) 파이프라인을 설정하는 것을 목적으로 합니다.

---

## 2. 주요 작업 및 개선 내역

### 1) Jekyll 처리 방지 (`.nojekyll`) 파일 생성
- GitHub Pages의 기본 Jekyll 빌드 엔진이 정적 파일 및 특정 디렉토리를 필터링하거나 누락시키는 현상을 방지하기 위해 저장소 루트에 `.nojekyll` 설정 파일 생성.

### 2) 아이폰 Safari PWA (전체화면 홈 화면 추가) 메타태그 및 고화질 아이콘 추가
- **`apple-touch-icon.png` (180x180)** 및 **`icon_192.png` (192x192)** 고해상도 생성 및 루트 배치.
- `index.html` 상단에 iOS 전용 전체화면 웹앱 메타태그 구성:
  ```html
  <link rel="apple-touch-icon" sizes="180x180" href="apple-touch-icon.png">
  <link rel="icon" type="image/png" sizes="192x192" href="icon_192.png">
  <link rel="icon" type="image/png" sizes="512x512" href="icon_512.png">
  <meta name="apple-mobile-web-app-capable" content="yes">
  <meta name="apple-mobile-web-app-status-bar-style" content="default">
  <meta name="apple-mobile-web-app-title" content="청춘장기">
  ```
- 이로써 아이폰에서 '홈 화면에 추가' 시 상단 주소창이 사라지고 순수 네이티브 앱과 100% 동일하게 전체화면으로 실행됩니다.

### 3) PWA 매니페스트(`manifest.json`) & 서비스 워커(`sw.js`) 최적화
- `manifest.json`: 192x192, 512x512, 180x180 규격별 PNG 아이콘 명시 및 배경색 `#F7EBD3` 적용.
- `sw.js`: 신규 아이콘 캐싱 목록 추가 및 캐시 버전 `senior-janggi-v1.1.0` 갱신으로 오프라인 100% 구동력 확보.

### 4) GitHub Actions 자동 배포 워크플로우 구축
- `.github/workflows/deploy-pages.yml` 생성:
  - `main` 브랜치에 웹 자원 변경 사항이 푸시될 때마다 GitHub Pages 공식 최신 액션(`actions/deploy-pages@v4`)이 즉각 실행되어 사이트를 실시간 자동 배포하도록 구성.

## 3. GitHub Pages 활성화 가이드 (저장소 설정)
저장소 관리자는 GitHub 웹 화면에서 단 1회 아래 설정을 확인하시면 됩니다:
1. GitHub 저장소(`https://github.com/psangho70/Janggi-for-Seniors`) 접속
2. 상단 메뉴 **[Settings]** ➜ 왼쪽 사이드바 **[Pages]** 탭 클릭
3. **Build and deployment** 항목의 **Source**를 **[GitHub Actions]**로 선택
4. 설정 즉시 워크플로우가 실행되어 `https://psangho70.github.io/Janggi-for-Seniors/`로 실시간 서비스 배포 완료!
